# Fotoğraflar

Anı Duvarı'na asılacak fotoğrafları ve ekran görüntülerini bu klasöre koy, sonra `js/data.js` içindeki `photos` listesine ekle:

```js
photos: [
  { src: 'assets/photos/ilk-mesaj.jpg', caption: 'İlk mesajımız', date: '2025-12-06' },
],
```

Büyük fotoğrafları uzun kenarı ~1600 px olacak şekilde küçültmek siteyi hızlandırır.
